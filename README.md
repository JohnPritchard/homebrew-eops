# JohnPritchard Eops

## How do I install these formulae?

`brew install johnpritchard/eops/<formula>`

Or `brew tap johnpritchard/eops` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "johnpritchard/eops"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
